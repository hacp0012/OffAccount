<h1 align="center">OA</h1>

OffAccount (OA) est une application de gestion financière personnelle conçue pour
suivre simplement ses comptes et mieux comprendre ses dépenses au quotidien.

[Visiter l'application en ligne](https://hacp0012.github.io/OffAccount/#/)

## Principes

- **Garder le contrôle de ses données** : les informations sont enregistrées
  localement sur l’appareil, dans la base de données du navigateur.
- **Fonctionner hors ligne** : l’application est conçue pour rester utilisable
  sans connexion Internet.
- **Suivre l’essentiel au même endroit** : comptes, revenus, dépenses,
  transferts, listes de courses et dettes.
- **Faciliter le suivi** : consulter des rapports filtrés, les imprimer ou les
  exporter en CSV compatible avec les tableurs.
- **Laisser le choix au démarrage** : commencer avec une base vide ou charger
  des données de démonstration.

OffAccount est un outil de suivi; les montants et rapports dépendent des
informations saisies par l’utilisateur.
